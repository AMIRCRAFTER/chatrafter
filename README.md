Welcome to Chatrafter!

With this program, you can send messages to others and even chat in groups!

  How to Use:

1. First, download the folder containing Chatrafter files from GitHub using the command below, or manually from the website:
   - git clone https://github.com/AMIRCRAFTER/chatrafter.git

2. After downloading, open the program folder using:
   - cd chatrafter

3. Then run the program with:
   - python start.py

4. Now enter the chat room code.
   - If you want to create a room, just enter a new code and the room will be created.
   - If you want to join an existing room, enter its code.

5. Enter your desired username.

6. You will now enter the chat room and can chat with your friends — either in groups or one-on-one!
